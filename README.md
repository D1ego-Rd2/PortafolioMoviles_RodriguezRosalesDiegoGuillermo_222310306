## ▶️ Ejecución del Proyecto
### Act 4.1 — Creación de un Mini Reproductor de Música en Flutter

Sigue los siguientes pasos para ejecutar el proyecto desde Visual Studio Code:

### 1️⃣ Crear el proyecto

Abrir la terminal de VS Code y ejecutar:

```bash
dart create analisis_datos
```

---

### 2️⃣ Entrar al directorio del proyecto

```bash
cd analisis_datos
```

---

### 3️⃣ Ejecutar el proyecto

```bash
dart run
```

---

## ✅ Resultado

El proyecto se ejecutará correctamente en consola mostrando el funcionamiento de la aplicación desarrollada en Dart/Flutter.

## ▶️ Ejecución del Proyecto
### Act 4.1 — Creación de un Mini Reproductor de Música en Flutter

Sigue los siguientes pasos para ejecutar correctamente el proyecto en Flutter desde Visual Studio Code.

---

### 1️⃣ Seleccionar el dispositivo de destino

En la barra inferior de Visual Studio Code, seleccionar el dispositivo donde se ejecutará la aplicación.

---

### 2️⃣ Seleccionar el escritorio de Windows

Elegir la opción:

```txt
Windows (desktop)
```

como dispositivo de ejecución.

---

### 3️⃣ Iniciar la aplicación

Abrir la terminal desde la parte superior de VS Code:

```txt
Terminal → New Terminal
```

y posteriormente iniciar la depuración del proyecto.

---

### 💻 Ejecución por comando

También es posible ejecutar la aplicación mediante el siguiente comando:

```bash
flutter run lib/main.dart
```

---

## ✅ Resultado

La aplicación Flutter iniciará correctamente en el escritorio de Windows, permitiendo visualizar el funcionamiento del mini reproductor de música.
