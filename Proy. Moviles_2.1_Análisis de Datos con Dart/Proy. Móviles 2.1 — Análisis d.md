# 📖 Descripción

Proyecto desarrollado en Dart para realizar análisis de datos utilizando archivos JSON, manejo de clases, funciones de búsqueda, filtrado y estadísticas.

---

# 🚀 Paso 1 — Crear el Proyecto en Dart

Abrimos la terminal de Visual Studio Code y ejecutamos:

```bash
dart create analisis_datos
```

---

## 📂 Entrar al proyecto

```bash
cd analisis_datos
```

---

# 📄 Paso 2 — Crear Archivo JSON

Dentro del proyecto creamos un archivo llamado:

```txt
datos.json
```

Este archivo almacenará la información utilizada para el análisis de datos.

---

# 🧩 Paso 3 — Crear Clase Registro

En el archivo:

```txt
bin/analisis_datos.dart
```

se crea la clase encargada del modelado de datos.

---

## ✅ Función de la clase

- Representar registros
- Organizar información
- Facilitar búsquedas y filtrados

---

# 📥 Paso 4 — Leer Archivo JSON

Se agrega una función para leer y convertir los datos del archivo JSON.

---

## 🔹 Funcionalidades

- Leer archivo
- Decodificar JSON
- Convertir datos a objetos

---

# 🔎 Paso 5 — Funciones de Búsqueda y Filtrado

Se agregan funciones para realizar consultas sobre los datos.

---

## ✅ Funciones implementadas

- Búsqueda de registros
- Filtrado de información
- Consultas específicas

---

# 📈 Paso 6 — Estadísticas

Se agregan funciones para generar estadísticas a partir de los datos almacenados.

---

## 📊 Ejemplos

- Conteo de registros
- Promedios
- Resultados generales

---

# 📤 Paso 7 — Exportar Resumen a JSON

Se implementa una función para exportar resultados nuevamente en formato JSON.

---

# 🖥️ Paso 8 — Crear Menú Interactivo

Se agrega el método principal:

```dart
main()
```

para interactuar con el usuario desde consola.

# ▶️ Paso 9 — Prueba del Proyecto
